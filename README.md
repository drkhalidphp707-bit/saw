# لوحة بوت واتساب

خدمة عربية متعددة الحسابات لإدارة مسارات الرد الآلي، جمع بيانات الزبائن، وربط واتساب عبر QR. يحصل كل حساب جديد على تجربة مجانية لمدة 3 أيام، وبعدها يحتاج إلى تفعيل من الإدارة.

## التشغيل محلياً

على macOS يمكنك الضغط مرتين على ملف `تشغيل الموقع.command`. لا تفتح
`public/index.html` مباشرة، لأن الواجهة تحتاج إلى خادم الـ API.

أو شغّله من Terminal:

```bash
cp .env.example .env
npm install
npm start
```

افتح `http://localhost:3000/auth.html` لإنشاء حساب. الوضع الافتراضي `demo` لتجربة المحادثة دون واتساب.

لوحة إدارة الحسابات متاحة على `http://localhost:3000/admin.html` وتستخدم قيمة `ADMIN_PASSWORD`.

## النشر على Railway

1. ارفع المشروع إلى GitHub وأنشئ Railway Project من المستودع.
2. أضف المتغيرات:
   - `ADMIN_PASSWORD`: كلمة مرور قوية للوحة إدارة الحسابات.
   - `ADMIN_WHATSAPP`: رقم الإدارة بصيغة دولية دون `+` ليظهر زر التواصل بعد انتهاء التجربة.
   - `MODE=whatsapp`: لتفعيل الربط الحقيقي.
   - `DATA_DIR=/data`: مسار الحفظ الدائم (اختياري؛ التطبيق يقرأ مسار الـ Volume تلقائياً أيضاً).
3. أضف Railway Volume واربطه بالمسار `/data`.
4. افتح `/auth.html` وسجل حساباً، ثم امسح QR من واتساب: الإعدادات ← الأجهزة المرتبطة ← ربط جهاز.
5. افتح `/admin.html` لتفعيل حساب، تمديد تجربته 3 أيام، أو إيقافه.

بدون Volume ستضيع الحسابات وجلسات واتساب وبيانات الزبائن عند إعادة نشر الخدمة. لكل حساب مجلد مستقل داخل مسار البيانات.

## تنبيه

اتصال QR يستخدم بروتوكول WhatsApp Web غير الرسمي. قد يتغير أو يتوقف، وتوجد احتمالية لتقييد الرقم. للحسابات التجارية الحساسة يُفضّل WhatsApp Cloud API الرسمي، لكنه لا يوفر ربط QR بهذه الطريقة.
